# 📊 Sales Forecasting Machine Learning Project

## 🚀 Overview

This project is a **Sales Forecasting System** built using Machine Learning and Flask.
It helps businesses predict future sales based on historical data and provides interactive dashboards for insights and decision-making.

---

## 🎯 Key Features

* 📈 **Sales Prediction using ML Models**
* 🧹 Data preprocessing and feature engineering
* 📊 Interactive dashboards for visualization
* 🔮 Scenario simulation & goal-based forecasting
* 👤 User authentication (Login/Register system)
* 📂 CSV upload for custom data prediction

---

## 🛠️ Tech Stack

**Frontend:**

* HTML, CSS

**Backend:**

* Python (Flask)

**Machine Learning:**

* Pandas
* NumPy
* Scikit-learn

**Database:**

* SQLite / SQL

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/SALES-FORECASTING.git
cd SALES-FORECASTING
```

### 2️⃣ Install dependencies

```
pip install -r requirements.txt
```

### 3️⃣ Run the application

```
python run_app_safe.py
```

### 4️⃣ Open in browser

```
http://127.0.0.1:5000/
```

1. Upload historical sales data (CSV)

3. Machine learning model is trained
4. Predictions are generated
5. Results displayed on dashboard
